Overview:
The Baobab Ridge Wildlife Rehabilitation Records System is a C# Windows Forms application developed for managing wildlife rehabilitation records. The system allows staff to add, view, update, and delete animal records while automatically determining each animal's rehabilitation status and housing unit based on its recovery score. The application also generates summary reports and stores all data using text files.

Features:
Add Animal
View All Animals
Search Animal by ID
Update Animal Records
Delete Animal Records
Automatic Status & Housing Classification
Generate Summary Reports
animals.txt
Stores animal records in the following format:
AnimalID|Name|Species|Age|RecoveryScore|Status|HousingUnit

How to Build and Run:
Clone the repository.
Open the solution in Visual Studio 2022 or later.
Ensure .NET 8 SDK (or newer) is installed.
Build the solution.
Run the application.
The starter animals.txt file will be copied to the output directory automatically.
